# KANBAN-752: AllianceMine Literature->Functional Complementation Template Broken

**URL:** https://agr-jira.atlassian.net/browse/KANBAN-752

## Request

> No results come up for this query - https://www.alliancegenome.org/bluegenes/alliancemine/templates/Literature_Complements. It just says, 'Error occurred when running template'. When you click on 'edit query' you get a 403 error from CloudFront.

## Assessment

**Status:** Done (Assigned to Christopher Tabone)

**Root Cause:** CloudFront WAF blocking the query request due to URL pattern matching rules.

### Query XML

```xml
<query model="genomic" view="Gene.primaryIdentifier Gene.secondaryIdentifier Gene.symbol
  Gene.complements.complement.primaryIdentifier Gene.complements.complement.symbol
  Gene.complements.complement.crossReferences.identifier
  Gene.complements.complement.crossReferences.source.name Gene.complements.direction
  Gene.complements.publication.pubMedId Gene.complements.source Gene.complements.notes"
  sortOrder="Gene.primaryIdentifier ASC">
  <join path="Gene.complements.complement.crossReferences" style="OUTER"/>
</query>
```

### Issue Analysis

The 403 error from CloudFront indicates the request is being blocked by AWS WAF rules. This typically happens when:

1. Query string is too long or contains special characters
2. Request matches a WAF rule pattern (SQL injection detection)
3. Rate limiting triggered

### Resolution

This is a CloudFront/WAF configuration issue, not an AllianceMine issue. The fix requires:

1. Review CloudFront WAF rules for alliancegenome.org
2. Add exception for InterMine API endpoints
3. Or modify the template query to avoid triggering WAF
